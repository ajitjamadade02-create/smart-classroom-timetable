Option 3 — Upload an Excel / PDF file

Instead of typing each person — Excel, CSV or PDF.
Works with a workload sheet like Sr. No · Name of Faculty · Designation · Class · Course Name (Course Code) · Theory · Tutorial · Practical · No. of Divisions · Sum — the code inside the brackets, the hours and the class text (e.g. SY(AIML)-B) are all read as written. Simpler sheets work too: only Faculty Name and a Course/Subject Code are required; Max Periods per Day, Division and Batch are optional. Imported people appear in the list below; the allocations also appear in step 07. A subject not yet set up is created from the file.
